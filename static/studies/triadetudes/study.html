Design

Pivots: click any scale note on a string of the set — that note and the next two scale notes up the same string become your pivots (dashed rings). The dashed box is your isolation zone.

Context & Motion

With a bass, every dot is relabeled relative to the new root — the same shape changes meaning. Order badges on the sounding notes show each string's slot(s) in the pattern.

Transport

BPM 72
Chords take the bar's slots in order — e.g. 5/4 split 2+3: first chord 2 beats, next chord 3, new bar. Accents: bar > chord > beat.
The étude — end to end (click a bar to jump there)
Echo staff — scratch pad for notes you click (keyboard or fretboard)

Triadetudes v1.0 — triad isolation étude designer. Colors per At-Etudes Design Spec v1.1
(red R · green 2 · blue 3 · silver 4 · black 5 · cyan 6 · amber 7; function relative to the
sounding root). The score shows the whole étude; the arpeggio pattern's note count against each
chord's beats sets the subdivision (4 notes over 2 beats = 8ths). Audio is synthesized; click any
note or key to hear it. The practice notebook saves each étude's full configuration with your
intention and outcome — history lives in this browser; Export keeps a markdown copy.
