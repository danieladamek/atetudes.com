A full metronome on its own clock — use it with or without the étude. The étude subscribes to this grid. (Shared component: every At-Etudes app carries this metronome, first block, this look.)

Design

Pivots: click any scale note on a string of the set — that note and the next two scale notes up the same string become your pivots (dashed rings). The dashed box is your isolation zone.

Context & Motion

With a bass, every dot is relabeled relative to the new root — the same shape changes meaning. Order badges on the sounding notes show each string's slot(s) in the pattern.

Transport

Chords take the bar's slots in order — e.g. 5/4 split 2+3: first chord 2 beats, next chord 3, new bar. If the metronome is running, Play joins it at the next bar — the click you already hear is your count-in. If it isn't, Play starts it (count-in adds one clicked bar first). Stopping the étude leaves a self-started metronome running; the metronome's Stop stops everything — it owns the clock. Mute chords: the changes still animate in time — play-along, you supply the triads.
